# Technology Selection for Hyperautomation

## Overview

A hyperautomation strategy should not mean using every available technology. Select capabilities based on the process requirement.

## Decision Guide

| Requirement | Potential capability |
|---|---|
| Structured workflow | Cloud flow |
| Desktop application | Power Automate for desktop |
| Unstructured document | AI-assisted processing |
| Existing API | Connector or HTTP integration |
| Complex orchestration | Multiple coordinated automation components |
| Process analysis | Process mining and analytics |

## Selection Questions

Ask:

1. Is the process stable?
2. Is an API available?
3. Is the input structured?
4. Does the task require human judgment?
5. What are the security and compliance requirements?
6. How will the solution be monitored and supported?
