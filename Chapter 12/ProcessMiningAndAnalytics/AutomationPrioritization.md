# Automation Opportunity Prioritization

## Overview

Process analysis can identify many possible automation opportunities. A prioritization model helps teams select candidates based on measurable value and risk.

## Evaluation Factors

Consider:

- Transaction volume
- Manual effort
- Business impact
- Process stability
- Exception rate
- Compliance risk
- Implementation complexity
- Expected maintenance

## Simple Model

```text
Business Value
      +
Feasibility
      -
Risk / Complexity
      ↓
Priority
```

## Good Candidate

A strong candidate is usually repetitive, stable, measurable, and valuable enough to justify implementation and ongoing support.
