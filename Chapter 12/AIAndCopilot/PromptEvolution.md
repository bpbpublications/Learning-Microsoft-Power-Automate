# Prompt Evolution

## Overview

AI-assisted automation is changing how users describe tasks, transform content, and generate automation logic. Prompt design therefore becomes an important automation skill.

## Prompt Pattern

```text
Business Goal
    ↓
Context
    ↓
Instructions
    ↓
Expected Output
    ↓
Validation
```

## Good Prompt Structure

Include:

- Clear objective
- Relevant context
- Required constraints
- Expected output format
- Validation criteria

## Example

Instead of:

> Summarize this email.

Use a more specific instruction such as:

> Summarize the email in three bullet points and identify any requested action and due date.

## Governance

Prompts used in business automation should be reviewed for accuracy, data exposure, and unintended outputs.
