## Ownership

Ownership should be treated as a separate responsibility from simple user access. Critical automations should have clear business and technical accountability.

## Suggested Learning Flow

```text
Identify Owner
     ↓
Determine Required Access
     ↓
Review Connections
     ↓
Share
     ↓
Test
     ↓
Review Access Periodically
```

## Security Principles

- Grant only the access required for the user's role.
- Do not share passwords or connection secrets.
- Review flow, connection, and data-source permissions separately.
- Document critical ownership and support responsibilities.
- Remove access that is no longer required.
