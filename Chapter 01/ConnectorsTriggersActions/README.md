# Connectors, Triggers, and Actions

At the core of every flow in Power Automate are connectors, triggers, and actions. Understanding what each of these components does — and how they work together — is key to building effective automations.

## Connectors

Connectors let Power Automate work with other apps and services, such as Microsoft 365, SharePoint, Outlook, Excel, Teams, Salesforce, and Dropbox.

**Example:** To save email attachments from Outlook to OneDrive, you would use the Outlook and OneDrive connectors together.

## Triggers

A trigger is what starts a flow. Every flow begins with one.

**Examples:**
- A file is added to a OneDrive folder.
- A new item is created in a SharePoint list.

## Actions

Actions are the steps that follow the trigger — they define what the flow should do.

**Examples:**
- Create a task in Planner.
- Post a message in Teams.

## Key Features and Capabilities

- **Connectors to applications** — Power Automate provides connectors that integrate with a wide range of applications, enhancing functionality and ease of use.
- **Templates for quick setup** — Pre-made templates let users quickly set up workflows, saving time and ensuring consistency.
- **Trigger-based actions** — Workflows can be initiated automatically based on specific conditions or events.
