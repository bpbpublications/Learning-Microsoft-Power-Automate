# Introduction to Power Automate and Microsoft 365

## Overview

This folder contains the companion resources for Chapter 1 of *Learning Microsoft Power Automate*.

This chapter sets the stage for working with automation using Microsoft Power Platform, focusing on Power Automate cloud flows and Power Automate Desktop (PAD). In a Microsoft 365 context, that means letting Outlook, SharePoint, Teams, Excel, and even older line-of-business apps pass data among themselves without constant human intervention.

## What You Will Learn

By completing this chapter, you will learn how to:

* Understand where Power Automate fits within the Power Platform and Microsoft 365 ecosystem.
* Recognize connectors, triggers, and actions and how they power automations.
* Navigate the Power Automate portal and understand the different flow types.
* Set up and configure a Power Automate environment.
* Install and launch Power Automate Desktop.
* Understand environments, solutions, and licensing models well enough to make informed choices when designing and deploying automations.

## Prerequisites

Before working through the exercises, make sure you have:

* Access to Microsoft Power Automate ([https://make.powerautomate.com/](https://make.powerautomate.com/)).
* A Microsoft account (personal or work).
* Windows 10 or 11 if you plan to install Power Automate Desktop.
* Basic familiarity with common Microsoft 365 apps (Outlook, SharePoint, Teams, Excel).

## How to Use These Resources

For the best learning experience:

1. Read the corresponding section of Chapter 1 in *Learning Microsoft Power Automate*.
2. Open the resource folder associated with the topic.
3. Follow along by signing in to the Power Automate portal and exploring the areas described.
4. Install Power Automate Desktop and try building a simple flow.
5. Use the licensing comparisons as a reference when deciding which plan fits your scenario.
