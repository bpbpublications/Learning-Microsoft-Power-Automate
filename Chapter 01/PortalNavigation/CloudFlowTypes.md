# Types of Cloud Flows

When building flows in Power Automate, cloud flows are where most of the action happens. Depending on the need — a scheduled task, a button you tap, or something that responds automatically to an event — there is a flow type that fits the job.

| Type of cloud flow | Suited for | Example |
|---|---|---|
| Automated cloud flows | Performing one or more tasks automatically after being triggered by an event | Generate reports via custom queries on your SQL database |
| Instant cloud flows | Performing one or more tasks instantly with the click of a button, triggered manually from your device | Save all your email attachments to a folder automatically |
| Scheduled cloud flows | Performing one or more tasks on a schedule — daily, weekly, or custom-defined | Auto-backup data to designated storage on a regular basis |
