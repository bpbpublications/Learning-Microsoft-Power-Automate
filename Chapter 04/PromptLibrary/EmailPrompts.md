# Email Prompts

## Overview

This prompt library provides reusable examples for generating professional customer communication with Copilot.

The prompts are designed to help structure follow-up emails and keep the generated content focused on the required business information.

## Follow-Up Email

Use this prompt when a customer interaction requires a professional follow-up.

```text
Create a professional follow-up email based on the information provided.
Summarize the discussion, mention the agreed actions,
and include the next steps.
Keep the tone polite and business-focused.
```

## Concise Follow-Up

Use this version when the email should be brief.

```text
Create a concise professional follow-up email.
Include the key discussion point, agreed action,
and next step. Keep the message brief and clear.
```

## Customer Status Update

```text
Create a professional customer status update email.
Summarize the current status, explain any important changes,
and clearly describe the next action.
```

## Action-Tracking Email

```text
Create a professional email summarizing the agreed actions.
For each action, identify the responsible party and the expected next step.
Use a clear and business-friendly tone.
```

## Meeting Follow-Up

```text
Create a professional meeting follow-up email.
Summarize the important discussion points,
list the agreed actions, and mention the next meeting or follow-up step.
```

## Prompt Guidelines

A stronger email prompt usually specifies:

- Purpose of the email.
- Intended audience.
- Important facts that must be included.
- Desired tone.
- Required actions or next steps.
- Preferred length.

For example:

```text
Create a professional and concise follow-up email.
Address the customer politely.
Mention the project delay, the agreed customer action,
and the next meeting date.
Do not add information that is not provided.
```

## Review Before Sending

Generated email content should be reviewed before it is sent.

Check:

- Recipient.
- Subject.
- Business facts.
- Dates and actions.
- Tone.
- Any information that was not present in the source context.
