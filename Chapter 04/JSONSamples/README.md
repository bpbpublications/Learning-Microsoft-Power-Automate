# JSON Samples

This folder contains sample JSON responses used by the Chapter 4 AI Builder examples.

The samples are intended for learning and demonstration purposes. They can be used to understand the structure of AI-generated output and to practice working with JSON in Power Automate.

## Files

| File | Related Example | Purpose |
|---|---|---|
| `InvoiceResponse.json` | Invoice Processing | Sample invoice extraction response |
| `OCRResponse.json` | OCR Examples | Sample OCR text response |
| `SentimentResponse.json` | Sentiment Analysis | Sample sentiment-analysis response |

## How to Use

The JSON files can be used to:

- Inspect sample AI Builder output.
- Practice accessing JSON properties.
- Build expressions in Power Automate.
- Test **Parse JSON** actions.
- Understand how extracted values can be used in downstream actions.

These files contain **sample data only** and are not intended to represent actual production responses.
