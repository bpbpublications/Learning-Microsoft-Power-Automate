# Automation Operating Model

## Overview

An operating model defines how automation work is requested, delivered, supported, and governed across an organization.

## Core Roles

Typical responsibilities include:

- Business process owner
- Automation developer
- Solution architect
- Platform or CoE team
- Operations and support team
- Security and governance stakeholders

## Lifecycle

```text
Idea
 ↓
Assessment
 ↓
Design
 ↓
Build
 ↓
Test
 ↓
Deploy
 ↓
Operate
 ↓
Retire
```

## Key Controls

Define ownership, support expectations, change management, documentation standards, access controls, and review points for critical automations.

## Benefits

A defined operating model reduces dependency on individual makers and provides a repeatable way to scale automation delivery.
