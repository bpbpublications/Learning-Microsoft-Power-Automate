# Automation Intake and Prioritization

## Overview

An enterprise automation program needs a consistent way to evaluate requests before development begins.

## Intake Flow

```text
Request
  ↓
Process Assessment
  ↓
Risk and Complexity Review
  ↓
Value Assessment
  ↓
Prioritize
  ↓
Approve / Reject / Defer
```

## Assessment Areas

Consider:

- Business value
- Process stability
- Transaction volume
- Manual effort
- Exception rate
- Data sensitivity
- Integration complexity
- Support requirements

## Prioritization

A simple prioritization model can balance business value against delivery complexity and risk.

Avoid automating a poorly defined or unstable process simply because it has high transaction volume.

## Documentation

Record the reason for the decision, expected outcome, owner, dependencies, and next review date.
