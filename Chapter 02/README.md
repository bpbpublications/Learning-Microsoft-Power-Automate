# Expressions and Power Fx

## Overview

This folder contains the companion resources for Chapter 2 of *Learning Microsoft Power Automate*.

This chapter focuses on using expressions and Power Fx to create dynamic automation logic, transform data, work with dates and text, handle variables, parse JSON, and build formulas used in Power Automate.

## What You Will Learn

By completing this chapter, you will learn how to:

* Work with expressions in Power Automate.
* Use string and date functions in automation workflows.
* Create and work with variables.
* Parse and work with JSON data.
* Build Power Fx formulas for automation scenarios.
* Combine these techniques to create dynamic automation logic.

## Chapter Resources

The resources for this chapter are organized into the following folders:

| Folder         | Description                                                                 |
| -------------- | --------------------------------------------------------------------------- |
| `Expressions/` | Examples and supporting files for Power Automate expressions and functions. |
| `PowerFx/`     | Power Fx formulas and examples used in the chapter.                         |
| `JSONSamples/` | JSON samples used for parsing, transformation, and data-handling exercises. |

## Prerequisites

Before working through the exercises, make sure you have:

* Access to Microsoft Power Automate.
* An appropriate Microsoft account and environment.
* The required Power Automate features and licenses for the exercises covered in this chapter.
* Basic familiarity with creating Power Automate flows.

## How to Use These Resources

For the best learning experience:

1. Read the corresponding section of Chapter 2 in *Learning Microsoft Power Automate*.
2. Open the resource folder associated with the exercise.
3. Recreate the examples while following the instructions in the book.
4. Modify the examples to understand how different expressions and formulas affect the result.
5. Use the provided samples as reference material when working through the exercises.
