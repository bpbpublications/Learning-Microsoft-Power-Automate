# Common String Expressions in Power Automate

## Concatenate

```text
concat('Hello ','World')
```

Output

```text
Hello World
```

## Convert To Uppercase

```text
toUpper('power automate')
```

Output

```text
POWER AUTOMATE
```

## Convert To Lowercase

```text
toLower('POWER AUTOMATE')
```

Output

```text
power automate
```

## Trim Spaces

```text
trim('   Power Automate   ')
```

Output

```text
Power Automate
```

## Substring

```text
substring('PowerAutomate',0,5)
```

Output

```text
Power
```

## Replace Text

```text
replace('Power Automate','Automate','Platform')
```

Output

```text
Power Platform
```

## String Length

```text
length('Power Automate')
```

Output

```text
14
```

## Contains

```text
contains('Learning Power Automate','Power')
```

Output

```text
true
```

## Starts With

```text
startsWith('Power Automate','Power')
```

Output

```text
true
```

## Ends With

```text
endsWith('Power Automate','Automate')
```

Output

```text
true
```
