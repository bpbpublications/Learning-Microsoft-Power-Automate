# Release Checklist

## Overview

A release checklist provides a repeatable set of checks before and after deploying an automation solution.

## Pre-Release

- Confirm solution version.
- Review change summary.
- Confirm dependencies.
- Validate connection references.
- Validate environment configuration.
- Complete functional testing.
- Complete regression testing where required.
- Obtain required approval.

## Deployment

- Deploy the approved package.
- Record deployment evidence.
- Monitor the deployment result.

## Post-Release

- Validate key business scenarios.
- Confirm expected flow state.
- Check monitoring and alerts.
- Communicate release completion.
- Record known issues.

## Stop Conditions

Do not continue the release when a critical validation or approval requirement has failed.
