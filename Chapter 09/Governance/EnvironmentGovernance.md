# Environment Governance

## Overview

Environment governance defines how Power Platform environments are created, accessed, monitored, and maintained.

## Governance Areas

Define standards for:

- Environment ownership
- Security roles
- Maker access
- Data protection
- Deployment permissions
- Monitoring
- Lifecycle and retirement

## Environment Classification

An organization may classify environments by purpose, such as:

```text
Development
Test / QA
Production
Sandbox
```

Each classification should have documented access and usage rules.

## Review

Review environment usage periodically and retire unused environments according to the organization's lifecycle policy.
