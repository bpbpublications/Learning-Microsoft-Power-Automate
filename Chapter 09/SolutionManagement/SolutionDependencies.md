# Solution Dependencies

## Overview

A solution can depend on components provided by other solutions or platform features.

## Examples

Dependencies may include:

- Tables
- Columns
- Choices
- Cloud flows
- Custom connectors
- Connection references
- Environment variables

## Dependency Review

Before deployment:

1. Identify required components.
2. Confirm the target environment contains required dependencies.
3. Review dependency warnings during solution operations.
4. Test the complete solution after deployment.

## Troubleshooting

If deployment fails because of a missing dependency, resolve the dependency rather than bypassing the deployment control.
