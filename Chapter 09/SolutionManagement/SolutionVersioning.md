# Solution Versioning

## Overview

Versioning provides traceability for solution changes and makes releases easier to identify and support.

## Versioning Practice

Use a consistent version format and increment it according to the organization's release policy.

Record:

- Solution name
- Version
- Change summary
- Release date
- Environment
- Approver

## Example

```text
Automation Solution
Version: 1.4.0
Change: Added customer notification flow
Environment: Test
```

## Why Versioning Matters

Version information helps teams:

- Identify what is deployed.
- Compare releases.
- Troubleshoot production issues.
- Roll back to a known release where supported.
- Maintain audit evidence.
