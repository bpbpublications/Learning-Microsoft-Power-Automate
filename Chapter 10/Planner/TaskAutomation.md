# Planner Task Automation

## Overview

Planner can be integrated with Power Automate to create and update tasks as business work progresses.

## Typical Pattern

```text
Business Event
      ↓
Create Task
      ↓
Assign Owner
      ↓
Set Due Date
      ↓
Update Status
```

## Common Scenarios

- Create tasks from forms.
- Create follow-up tasks from emails.
- Assign work after approval.
- Update task status from business events.
- Notify owners about overdue work.

## Best Practices

- Define task ownership.
- Validate due dates.
- Prevent duplicate task creation.
- Use meaningful titles and descriptions.
- Review permissions and team membership.
