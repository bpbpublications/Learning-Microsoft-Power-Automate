# Microsoft Planner Integration

This section covers Power Automate integration with Microsoft Planner for task and work-item automation.

## Topics

- Creating Planner tasks
- Updating task status
- Assigning tasks
- Due dates and follow-up
- Notifications and escalation

## Learning Flow

```text
Business Event
      ↓

      ↓
Assign Owner
      ↓

      ↓
```
