# Office Scripts

## Overview

Office Scripts can extend Excel automation when workbook logic is better handled through reusable scripts.

## Suggested Topics

- Script fundamentals
- Parameters and return values
- Running scripts from Power Automate
- Data transformation
- Formatting and workbook operations
- Error handling and validation

## Learning Flow

```text
Excel Workbook
     ↓
Office Script
     ↓
Transform / Validate
     ↓
Power Automate
     ↓
Continue Business Process
```
