# Excel Integration

This section covers Power Automate integration with Excel workbooks and tables.

## Topics

- Reading and writing Excel table data
- Adding and updating rows
- Processing workbook-driven business data
- Excel file automation
- Office Scripts integration
- Validation and error handling

## Learning Flow

```text
Excel File / Table
       ↓
Read Data
       ↓
Apply Logic
       ↓
Update Workbook
       ↓
Validate Result
```

For workbook operations that require more advanced Excel logic, see the [Office Scripts](../OfficeScripts/) section.
