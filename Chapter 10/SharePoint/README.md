# SharePoint Integration

This section covers Power Automate integration with SharePoint for document, list, and collaboration scenarios.

## Topics

- Creating and updating SharePoint items
- Document library automation
- File and folder processing
- Metadata and content management
- Approval and notification patterns
- SharePoint-triggered flows

## Learning Flow

```text
SharePoint Event
      ↓
Read Item / File
      ↓
Process Business Logic
      ↓
Update / Create
      ↓
Notify or Approve
```
